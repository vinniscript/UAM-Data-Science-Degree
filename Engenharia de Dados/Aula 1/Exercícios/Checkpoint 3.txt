Exercício 1


Explique a diferença entre:

CREATE SCHEMA auditoria;

e:

CREATE TABLE auditoria.controle_aulas (...);

R: CREATE SCHEMA auditoria cria um schema chamado auditoria e CREATE TABLE auditoria.controle_aulas cria uma tabela chamada controle aulas dentro diretamente dentro do schema auditoria

Exercício 4


Qual a diferença entre estas validações?

SELECT name
FROM sys.schemas
WHERE name IN ('origem', 'staging', 'qualidade');

e:

SELECT COUNT(*)
FROM sys.schemas
WHERE name IN ('origem', 'staging', 'qualidade');

R: Um está filtrando por nomes dentro da lista de schemas, o outro está contando quantos da lista tem no schema. Um devolverá uma lista com o os nomes chamados, o outro retornará um valor de quantos haviam dos nomes chamados
