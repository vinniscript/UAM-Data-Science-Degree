Exercício 1:

Explique a diferença entre:

  USE DataCommerce;

e

  CREATE DATABASE DataCommerce;

R: USE seleciona o banco Datacommerce, caso já criado, para o contexto atual, já o CREATE criará o banco

---

Exercício 2

O que acontecerá se DataCommerce já existir?

IF DB_ID('DataCommerce') IS NULL
BEGIN
CREATE DATABASE DataCommerce;
END;

Escolha uma alternativa:

1. O banco será apagado e recriado.
2. Outro banco com o mesmo nome será criado.
3. O bloco de criação não será executado.
4. O SQL Server mudará automaticamente para o banco.

R: 3

Exercício 3

Depois deste script:

USE master;
GO
 
USE DataCommerce;
GO
 
SELECT DB_NAME() AS banco_atual;

Qual deverá ser o resultado e por quê?

R: DataCommerce, pois foi o último a ser chamado pelo USE

Exercício 5

Leia este script, mas não execute ainda:

USE master;
GO
 
SELECT DB_NAME() AS banco_1;
GO
 
USE DataCommerce;

1. Quantos lotes existem?
2. Quantos conjuntos de resultados serão exibidos?
3. Qual valor deverá aparecer em banco_1?
4. Qual valor deverá aparecer em banco_2?
