Exercício 1
Explique com suas palavras a função de cada coluna da tabela:
- aula -> ID da aula, o identificador de cada uma das aulas
- tema -> Qual foi o assunto da aula
- data prevista -> Data agendada para ingresso do docente.
- concluída -> Binário, retornando se a aula teve ou não sua conclusão
- data registro -> Quando foi registrada a aula

Exercício 2
Explique a diferença entre NULL e NOT NULL.

Resposta: NULL é a ausência de um valor. Uma coluna que foi criada, porém não foi inserido valores, por exemplo.
Já NOT NULL é uma regra, onde aquela coluna não pode haver valores não inseridos. Há de ter algo ali.


Exercício 3
Por que a coluna aula foi definida como PRIMARY KEY?
O que deve acontecer se tentarmos inserir duas linhas com aula = 1?

Resposta: Pois a aula é um número inteiro, um facilitador na hora de buscar. Ela é nosso identificador sobre cada tema, registro, conclusão, etc.
Se tentar inserir duas linhas com o mesmo ID dará erro, pois uma coluna definida como primary key não pode ter valores iguais.

Exercício 6

SELECT * FROM auditoria.controle_aulas;
