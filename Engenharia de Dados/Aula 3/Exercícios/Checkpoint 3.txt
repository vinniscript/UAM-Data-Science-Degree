9. Escreva uma consulta que conte quantas linhas existem em cada uma destas tabelas:
- origem.clientes
- origem.produtos
- origem.pedidos
- origem.itens_pedido

Resposta: SELECT 'origem.clientes' AS tabela, COUNT(*) AS total_linhas FROM origem.clientes
UNION ALL
SELECT 'origem.produtos', COUNT(*) FROM origem.produtos
UNION ALL
SELECT 'origem.pedidos', COUNT(*) FROM origem.pedidos
UNION ALL
SELECT 'origem.itens_pedido', COUNT(*) FROM origem.itens_pedido;



10. Explique o que significa dizer que uma operação DML respeitou a integridade referencial.

Resposta: Em termos práticos, respeitar os dados existentes e válidos na tabela, não referenciar algo inválido como um id de um cliente que não existe numa FK de outra tabela.
